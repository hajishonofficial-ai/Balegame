# 🎮 ربات بازی‌های ۲ نفره برای اپلیکیشن بله

یک ربات حرفه‌ای و کامل برای بازی‌های ۲ نفره در پیام‌رسان بله با استفاده از کتابخانه Balethon.

## ✨ ویژگی‌ها

### 🎲 بازی‌های موجود:
1. **سنگ کاغذ قیچی** - بازی کلاسیک و سریع
2. **دوز (Tic Tac Toe)** - بازی فکری روی صفحه ۳×۳
3. **حدس عدد** - حدس عدد بین ۱ تا ۱۰۰ با راهنمایی
4. **جنگ اعداد** - مقایسه کارت‌های تصادفی

### 💰 سیستم شرط‌بندی:
- اعتبار اولیه: **۱۰۰۰ سکه** برای هر کاربر جدید
- امکان شرط‌بندی اختیاری (۱۰۰، ۲۰۰، ۵۰۰، ۱۰۰۰، ۲۰۰۰ سکه)
- امکان بازی بدون شرط
- برنده تمام مبلغ شرط را می‌برد (۲ برابر)
- در صورت مساوی، شرط برگشت می‌خورد

### 🏆 امکانات جانبی:
- پروفایل کاربری با آمار بازی‌ها
- جدول برترین‌ها
- نرخ برد و باخت
- مچ‌میکینگ تصادفی هوشمند
- ذخیره‌سازی پایدار اطلاعات کاربران

## 🚀 نصب و راه‌اندازی

### ۱. نصب پیش‌نیازها:
```bash
pip install balethon
```

### ۲. دریافت اطلاعات ربات از بله:
- به [پنل توسعه‌دهندگان بله](https://developers.bale.ai/) مراجعه کنید
- یک ربات جدید بسازید
- API ID، API Hash و Bot Token را دریافت کنید

### ۳. تنظیمات کد:
فایل `bale_bot.py` را باز کنید و خطوط زیر را با اطلاعات خود جایگزین کنید:

```python
API_ID = 'YOUR_API_ID'      # اینجا API_ID خود را وارد کنید
API_HASH = 'YOUR_API_HASH'  # اینجا API_HASH خود را وارد کنید
BOT_TOKEN = 'YOUR_BOT_TOKEN'  # اینجا توکن ربات خود را وارد کنید
```

### ۴. اجرای ربات:
```bash
python bale_bot.py
```

## 📱 نحوه استفاده

### شروع کار:
1. ربات را در بله استارت کنید (`/start`)
2. دکمه **«🎮 شروع بازی»** را بزنید
3. نوع بازی مورد نظر را انتخاب کنید
4. مقدار شرط را انتخاب کنید (یا «بدون شرط»)
5. صبر کنید تا حریف پیدا شود
6. بازی کنید و برنده شوید! 🏆

### دستورات ربات:
- `/start` - شروع ربات و دریافت منو
- `🎮 شروع بازی` - ورود به بخش بازی‌ها
- `📊 پروفایل من` - مشاهده آمار و اعتبار
- `🏆 جدول برترین‌ها` - مشاهده بهترین بازیکنان
- `❓ راهنما` - نمایش راهنمای کامل

## 🎯 جزئیات بازی‌ها

### سنگ کاغذ قیچی:
- هر دو بازیکن همزمان انتخاب می‌کنند
- برنده بلافاصله مشخص می‌شود
- سریع و هیجان‌انگیز!

### دوز:
- صفحه ۳×۳
- بازیکن اول با ❌ شروع می‌کند
- بازیکن دوم با ⭕ بازی می‌کند
- استراتژی و فکر نیاز دارد!

### حدس عدد:
- عدد تصادفی بین ۱ تا ۱۰۰
- ۱۰ فرصت برای هر تیم
- راهنمایی «برو بالاتر» یا «برو پایین‌تر»
- هیجان تا آخرین لحظه!

### جنگ اعداد:
- ۲۶ کارت برای هر بازیکن (اعداد ۱-۱۳)
- ۲۶ دور بازی خودکار
- بیشترین برنده دورها برنده نهایی است
- کاملاً شانسی و سرگرم‌کننده!

- `users_data.json` - فایل ذخیره‌سازی اطلاعات کاربران (خودکار ساخته می‌شود)
- `README.md` - این فایل راهنما

## 🔧 ساختار کد

### کلاس‌های اصلی:
- `UserDataManager` - مدیریت داده‌های کاربران
- `Game` - کلاس پایه بازی‌ها
- `RockPaperScissors` - بازی سنگ کاغذ قیچی
- `TicTacToe` - بازی دوز
- `GuessNumber` - بازی حدس عدد
- `NumberWar` - بازی جنگ اعداد

### سیستم مچ‌میکینگ:
- صف انتظار هوشمند
- تطبیق بر اساس نوع بازی و مقدار شرط

## ⚠️ نکات مهم

1. **امنیت**: اطلاعات API خود را با کسی به اشتراک نگذارید
2. **ذخیره‌سازی**: فایل `users_data.json` را پاک نکنید
3. **اعتبار**: اگر اعتبار کاربر به صفر برسد، می‌تواند بدون شرط بازی کند
4. **خطاها**: تمام خطاها به صورت داخلی مدیریت شده‌اند
